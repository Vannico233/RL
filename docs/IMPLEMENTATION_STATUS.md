# 实施状态

资源更新（2026-10-30）：用户已确认 2 张 H200、每张约 143GB，可新建 Conda 环境；模型和数据均需下载。目标仓库为 https://github.com/Vannico233/RL 。

主线选择 Qwen2.5-VL-7B-Instruct、语言侧 LoRA、冻结视觉编码器与连接层，一张卡训练、一张卡生成。具体资源占用必须通过服务器试跑确认。

## 已实现

- 官方 ChartQA 目录读取、文件/像素哈希、跨划分去重、固定题池与 pilot 子集。
- 严格动作解析、答案评分、原图裁剪、两次尝试预算、最终回答机会。
- O0–O4 观察方式与 D0 人工区域诊断接口；D0 限验证集。
- B1/B2 输入导出，实际图片回传，ms-swift v4.6.0 调度器及规则奖励插件。
- 完整覆盖评分、human/augmented 分组、缺失成本覆盖率、同图聚类配对 bootstrap。
- Transformers 模型评估入口、逐轮记录、真实图片案例保存、失败运行状态。
- 固定 revision 的资产下载与安全解压、候选环境安装文件。
- 双卡训练/生成启动、所属进程清理、checkpoint 恢复和版本/硬件 preflight。
- 非零梯度、参数指纹、采样/损失 token、图像网格和生成端同步的审计及 G1 验收。
- 仅使用人工核查训练题的可选工具 SFT；合并后作为 B0/B1/B2 共同初始化。
- pilot 与最终评估矩阵、训练/评估成本汇总、含原图裁剪框的离线案例查看器。
- 完整服务器操作指南、待填实验报告及 GitHub Actions CPU 检查。

## 需要在服务器完成

- 安装候选 GPU 环境，通过 preflight；下载模型和数据并生成实际划分清单。
- 真实 7B 多轮推理、GRPO 更新、adapter 同步以及 G1 验收。
- G2 工具价值诊断、B1/B2 训练、验证集选 checkpoint、完整固定测试评估。
- 根据真实数据填写报告，保留正结果、负结果、成本与失败案例。

## 验证边界

已执行的单元测试覆盖项目本身的逻辑；调度器测试使用明确标注的框架接口替身。测试数、执行时间和对应源码哈希见 [`cpu-validation.json`](../reports/cpu-validation.json)。这些测试验证数据泄漏防护、原图裁剪与坐标、两次预算、评分边界、缺失成本、失败状态、案例导出和运行命令构建。

未安装本地 GPU 训练环境，未执行真实模型推理、GRPO 更新或取得科学实验结果。测试替身与人工构造的数据只出现在 CPU 测试中，不用于实验结果。

框架源码已核查至正式版 v4.6.0，commit `ad818a2cdfafaf4305ac40c4acd892a211978bc2`。候选 Python 包版本已核查存在性与主要依赖范围，完整 GPU 组合尚未实测。

2026-10-31：针对 GitHub 克隆中断，安装入口改为固定提交的官方源码压缩包，并固定 SHA256。已实际完成下载、构建和独立目录的无依赖安装，核对关键源码与固定 Git 提交一致；记录见 [`framework-source-install-validation.json`](../reports/framework-source-install-validation.json)。这项检查不包括 GPU 依赖安装或框架运行时导入。

静态接口记录见 [`swift-source-contract.json`](../reports/swift-source-contract.json)。它不能验证运行时导入、CUDA 算子、实际损失掩码或权重同步；这些必须通过服务器日志与 G1 验证。

最初任务书中的四卡、80GB、3B 是访谈阶段假设；本次实现以用户后续确认的 **2×H200、约 143GB/卡** 为准，选择 7B 语言侧 LoRA，保留一周范围。科研实验的完成定义不因代码交付而改变。
